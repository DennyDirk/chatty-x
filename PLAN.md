Этот самостоятельный ExecPlan поддерживается по `PLANS.md`. Progress, Surprises & Discoveries, Decision Log и Outcomes & Retrospective обновляются при работе. Нельзя объявлять будущие команды или непроведённые проверки существующими результатами.

## Purpose / Big Picture


Владелец подключает до трёх личных Telegram-аккаунтов через TDLib, выбирает до 100 личных чатов и включает естественные текстовые ответы. Приложение понимает текст, фотографии и голосовые, объединяет серии входящих и хранит память отдельно для каждого собеседника. Ручной ответ из браузера или другого Telegram-клиента ставит чат на паузу до явного возобновления.

Первый релиз: один владелец, десять одновременно активных диалогов, Linux VPS 4 vCPU / 8 GB RAM как начальная конфигурация для проверки. Русский адаптивный интерфейс, светлая/тёмная тема. Нет публичной регистрации, тарифов, групп, каналов, секретных чатов, звонков, исходящего аудио, обработки видео/документов, платежей и инициативных сообщений. Второй канал существует только как FakeMessagingAdapter для тестов.

### M2: Telegram


MessagingAdapter преобразует TDLib в нормализованные события. Авторизация показывает актуальные состояния: QR, номер, код, 2FA и дополнительные шаги выбранной ревизии. Коды/пароли не сохраняются. Импорт не создаёт ответы. Живые события во время загрузки отделяются historical-флагом и объединяются по ID. Повторная загрузка без дублей. Периодическая сверка и восстановление после отключения обязательны.

### M3: интерфейс переписки


Три области: чаты слева, сообщения в центре, скрываемая панель справа. Фильтры аккаунта/паузы/ошибок/нужных действий, поиск, курсорная история, SSE. Источник исходящего виден внутри сервиса. На телефоне области открываются последовательно. Ручная отправка защищена idempotency key — ID запроса против двойного клика. Собственная автоотправка не вызывает ручную паузу. Ручное сообщение из любого клиента отменяет неотправленные задания и ставит паузу до возобновления. Глобальная остановка доступна всегда.

### M4: генерация и доставка


Сначала сохранить входящее, затем планировать. Debounce — ожидание серии: 8 секунд тишины, максимум 30 секунд накопления до начала обработки. Одна генерация на чат, таймеры/задания в БД. После генерации задержка 2–6 секунд, один текстовый ответ на серию. Новые/изменённые/удалённые сообщения, настройки/память и ручные действия повышают версию и отменяют старый ответ. При непрерывных входящих отправка может ждать больше 30 секунд.

Перед dispatch проверить разрешения аккаунта/чата, глобальную паузу, версии, соединение, бюджет и расписание. Состояния READY/SENDING/SUBMITTED/SENT/FAILED/UNKNOWN/CANCELLED разделены. Хранить operation ID, temporary ID, final ID. SENT только после подтверждения TDLib. При аварии сверять известные идентификаторы; без доказательства UNKNOWN, никаких слепых повторов или сопоставления только по тексту. Однозначную доотправочную ошибку можно повторить ограниченно; FloodWait учитывает серверный срок. Переданный запрос нельзя гарантированно отменить. После восстановления входящие старше часа требуют владельца.

### M5: характер, модели, настройки


Наследование общие → аккаунт → чат; удаление override возвращает наследование, массивы заменяются полностью. Показать источник значения. Настройки: длина, обращения, теплота, юмор, дерзость, сленг, мат, эмодзи/смайлы, регистр, пунктуация, вопросы, темы/границы. По умолчанию коротко, без канцелярита, умеренный юмор и редкие эмодзи. Учитывать настроение, не создавать искусственные опечатки, не придумывать биографию/занятия/местоположение. Реакции на вопросы о боте — настраиваемые примеры, не hardcode. Пример: «Я Мэдди :) С чего такие подозрения?»; серьёзное раздражение переводит тон к спокойному ответу/владельцу.

Вкладка договорённостей: встречи, обещания, деньги, личные решения. Режимы: обсуждать без обязательства, черновик, автоматический ответ в пределах правила. По умолчанию окончательное решение у владельца; платёжных инструментов нет. Структурированный результат модели reply/skip/handoff, текст и категория причины; внутренние рассуждения не сохранять. Промпты версионировать; переписка/извлечённый текст — недоверенные данные, не системные команды.

Локальная память, Responses store=false, без зависимости от remote conversation; это не обещание отсутствия служебных логов провайдера. Модели меняются в настройках. ### M6: память


Контекст состоит из анкеты, свежих сообщений/серии, резюме, релевантных фактов. Факт содержит субъект, тип, содержание, дату, источник и закрепление. Предположения не факты. Исправление заменяет незакреплённое; конфликт pinned показывает владельцу. Забывание блокирует повторное извлечение из тех же источников. Изоляция connection+chat; общая анкета отдельно. PostgreSQL полнотекстовый поиск, без векторного сервера; лимит токенов, не вся история в каждом запросе. Начальная память из истории, обновление по завершённым сериям; неотправленные черновики не реальные события. Изменение/удаление источника инвалидирует производную память. UI позволяет смотреть/править/закреплять/забывать.

### M7: вложения

### M8: эксплуатация


Caddy HTTPS и frontend, PostgreSQL не публиковать. Мастер-ключ вне БД и backup. Логи только ID/категории без личных текстов/секретов. Хранение настраиваемо: сообщения 180 дней, файлы 30, backup 14. Незакреплённые факты истекают с источниками; pinned до удаления. Исчезающие сообщения не запоминать надолго, удаление очищает копии. Экспорт/удаление локальных данных не означает удаление Telegram. Цели RPO 24 часа (потеря локальных данных), RTO 2 часа (восстановление) подтверждаются упражнением. Диагностика очереди/ошибок/расходов, без выдуманного «сэкономленного времени».

## Idempotence and Recovery


Flyway migrations неизменяемы после применения. Ручные запросы уникальны по ключу, входящие по аккаунту/чату/ID. Задания/outbox обновляются транзакционно с блокировкой чата; сетевые вызовы не держат долгую транзакцию. Утративший lease обработчик не записывает новый результат. Ошибка AI не создаёт отправку. Restore требует разблокировки. Не удалять пользовательские volumes/сессии ради тестов; отдельные тестовые БД/каталоги.
